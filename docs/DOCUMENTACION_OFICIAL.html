1. Análisis de Requerimientos (-5 pts no entregarlo)

El presente proyecto consiste en el análisis, diseño e implementación de la plataforma web empresarial denominada "Parnet Ingeniería". El sistema responde a la necesidad de dotar a una empresa de infraestructura tecnológica de un canal digital público que integre medios multimedia (video, audio, galerías optimizadas), descarga de especificaciones técnicas en PDF, canales seguros de contacto y solicitud de servicios con validación antibot (CAPTCHA), así como un módulo administrativo privado para mantenimiento de inventarios y analítica de datos en tiempo real.

1.2 Restricciones Técnicas Oficiales de la Rúbrica

  • Prohibición estricta de PHP: Backend desarrollado en Node.js y Express con módulos ESM.
  • Paradigma Orientado a Objetos (POO): Modelos y servicios implementados con clases y encapsulamiento.
  • Patrón de Diseño Singleton: Conexión única y compartida de la base de datos relacional.
  • ORM Obligatorio: Sequelize para abstracción y consistencia de datos relacionales.

1.3 Configuración para correo de contacto

El envío se realiza con Resend mediante variables de entorno. Se requiere una API key y un dominio remitente verificado; el ejemplo de configuración está en backend/.env.example. Sin credenciales válidas, la API informa un error y no confirma el envío.

2.2 Implementación del Patrón de Diseño Creacional: SINGLETON

Para dar cumplimiento a la rúbrica oficial de 5 puntos correspondiente al patrón Singleton, se implementaron DatabaseConnection (backend/src/config/Database.js) y AppConfig (backend/src/config/AppConfig.js). La primera comparte la instancia Sequelize; la segunda centraliza la configuración del servidor y carga las variables de entorno antes de inicializar la conexión: 

class DatabaseConnection {
  constructor() {
    if (DatabaseConnection.instance) {
      return DatabaseConnection.instance;
    }
    this.sequelize = new Sequelize({
      dialect: 'sqlite',
      storage: process.env.DB_STORAGE || './database.sqlite',
      logging: false
    });
    DatabaseConnection.instance = this;
  }

  getSequelize() {
    return this.sequelize;
  }
}

const databaseConnectionInstance = new DatabaseConnection();
export default databaseConnectionInstance;

4. Programación y Buenas Prácticas (POO) (-5 pts no entregarlo)

La base de código se diseñó siguiendo los principios de la Programación Orientada a Objetos (POO): encapsulamiento, responsabilidad única y modularidad.

4.1 Servicios Desacoplados

  • PdfService: Encapsula la lógica de maquetación vectorial en PDFKit para emitir fichas técnicas profesionales con encabezados institucionales, paleta corporativa y pie de página.
  • ExcelService: Encapsula la librería ExcelJS para dar estilo formal a los reportes de sugerencias con celdas de encabezado con color de marca y anchos automáticos.
  • CaptchaService: Clase gestora de retos antibot con expiración automática periódica cada 10 minutos.
  • AppConfig: Singleton que carga las variables de entorno y centraliza los parámetros del servidor, la base de datos, CORS, JWT y correo.

5. Pruebas de Software (-5 pts no entregarlo)

El sistema integra dos suites de pruebas automatizadas que se ejecutan directamente en consola, verificando la integridad de la base de datos, los servicios y la seguridad criptográfica:

5.1 Suite de Flujo Funcional (npm run test:flow)

Casos incluidos en la suite (ejecutar antes de entregar):
  • Conexión Singleton a SQLite.
  • Búsqueda y filtrado del catálogo por categoría.
  • Generación SVG y validación de CAPTCHA.
  • Registro de solicitud de servicio y folio.
  • Generación de la ficha técnica PDF.

5.2 Suite de Seguridad y Autenticación (npm run test:security)

Casos incluidos en la suite (ejecutar antes de entregar):
  • Verificación de contraseñas mediante bcrypt y rechazo de claves inválidas.
  • Emisión, firma y verificación de tokens jsonwebtoken (JWT).
  • Rechazo de tokens alterados y control de roles administrativos.

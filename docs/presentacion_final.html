2. Diseño y Arquitectura de Software

Desacoplamiento total Monorepo con Backend MVC Orientado a Objetos y Frontend React SPA.

🏛️ Capa de Presentación (Frontend)

React 18 + Vite con arquitectura SPA responsiva.

  • Ruteo modular con react-router-dom y guardias privadas (ProtectedRoute).
  • Consumo de API centralizado con Axios e interceptores JWT.
  • Visualización gráfica en tiempo real con Chart.js.
  • Componente reactivo de CAPTCHA con recarga dinámica sin refresco de página.

⚙️ Capa de Servicios y Negocio (Backend)

Node.js con Express estructurado en MVC y POO estricto.

  • Patrón Singleton: Clase DatabaseConnection para conexión única de ORM Sequelize.
  • Capa de Servicios: PdfService, ExcelService, CaptchaService.
  • Autenticación por tokens criptográficos jsonwebtoken (JWT) y hash bcryptjs.
  • Persistencia relacional portátil (SQLite) que no requiere configuraciones externas en la entrega ZIP.

3. Modelo Físico de Base de Datos

Persistencia mediante ORM Sequelize con integridad relacional y migraciones/seeders.

Tabla / Modelo Campos Clave Propósito en el Negocio
usuarios id, username, password (bcrypt), email, rol Control de acceso privado a administradores.
productos id, codigo, nombre, categoria, precio, imagen_url, estatus Catálogo de telecomunicaciones y generación de Ficha PDF.
servicios_solicitudes id, folio, cliente_nombre, email, area, detalle, estatus Solicitud técnica por área con CAPTCHA para Dashboard 1.
sugerencias id, nombre, email, mensaje, created_at Buzón interno con CAPTCHA, paginación y exportación Excel/PDF.
noticias id, titulo, contenido, categoria, activo Tablero dinámico de novedades en el portal público.
visitas id, ip, userAgent, ruta, created_at Visitas por ruta y sesiones activas que reportan latido cada minuto, con vencimiento a los dos minutos.
